# 🔧 Taller Mecánico API

API REST para la gestión de un taller mecánico, desarrollada con NestJS y PostgreSQL.

## 📋 Descripción

Sistema backend para administrar las operaciones de un taller mecánico, incluyendo:
- Gestión de clientes
- Registro de vehículos
- Órdenes de trabajo con estados
- Validación de datos

## 🚀 Tecnologías

| Tecnología | Versión | Descripción |
|------------|---------|-------------|
| [NestJS](https://nestjs.com/) | 11.x | Framework backend Node.js |
| [TypeScript](https://www.typescriptlang.org/) | 5.x | Superset tipado de JavaScript |
| [PostgreSQL](https://www.postgresql.org/) | 18.x | Base de datos relacional |
| [TypeORM](https://typeorm.io/) | 0.3.x | ORM para TypeScript |
| [Docker](https://www.docker.com/) | - | Contenedor para PostgreSQL |
| [class-validator](https://github.com/typestack/class-validator) | - | Validación de DTOs |
